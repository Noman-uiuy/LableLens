RULES & METHODOLOGY

Checking criteria

A transparent screening baseline for packaged commodity declarations in India.

From photograph to finding

Read

02

Screen

THE STANDARD OF EVIDENCE

Detection is a starting point.

One photograph cannot establish every declaration’s placement, readability, physical size, or a product’s legal category.

These six checks cover a defined inspection scope. Category-specific exceptions and the current applicable notifications must be reviewed before enforcement action.

Sign-in records the reviewer’s account identity. It does not verify government employment or authority.

INSPECTION GUIDE

How to inspect a product

One workflow for consumers, retailers and inspection teams.

Try it with a real package

  1. Capture the evidence. Photograph the front, back and price/date stamp. Use a flat, well-lit package with readable English or Hindi text.
  2. Read and compare. Run OCR, compare the transcription with the package and correct errors. Code scanning records an identifier only.
  3. Check the declarations. Choose the right category and import context. Review detected text, rule references and next steps.
  4. Keep the record. Save the inspection, view the original photo and download PDF, editable Word or JSON. Sign in to append a reviewer assessment.

Read the result correctly

Detected declaration

The system found candidate text. Compare the value and its source with the actual package.

Needs review

A reading error, missing panel, uncertain rule applicability or unmeasured physical property prevents a reliable conclusion.

Potential non-compliance

A supported check found an issue after the required evidence verification. Review its rule and reasoning before acting.

OCR confidence

This is the reader’s confidence in the text, not a measured accuracy rate or a probability of legal compliance.
